# PO Learning Journal · Diário de estudos de Product Owner

**Português (Brasil)** | [English below](#english)

Este repositório é o meu diário de estudos para me tornar **Product Owner (PO)**: a pessoa que representa o cliente e o negócio dentro do time, decide **o que** será construído e em **qual ordem**, e cuida para que o produto entregue valor de verdade.

Aqui eu registro, com as minhas palavras, o que aprendo nos cursos que faço, organizados pela escola ou plataforma onde cada curso foi feito. O primeiro é o da **Tera**.

As notas são resumos próprios. Os materiais originais pertencem a cada escola, e os links levam até eles.

## Como este repositório está organizado

```
po-learning-journal/
├── cursos-courses/            Cursos, separados por escola ou plataforma
│   └── tera/                  Tera
│       └── <curso>/           Um curso
│           └── 01-<modulo>.md     Nota de estudo do módulo
├── glossario-glossary.md      Termos de produto em português e inglês
├── templates/                 Modelos (história de usuário, critérios de aceite, etc.)
└── exemplos-examples/         Exercícios e artefatos que eu fiz praticando
```

**Regra para cursos novos:** `cursos-courses/<escola>/<curso>/<número>-<módulo>.md`, com nomes em letras minúsculas e palavras separadas por hífen. Toda nota começa com uma tabela que diz a escola, o curso, o módulo, a situação e o link da fonte original.

Algumas pastas só aparecem no GitHub quando recebem o primeiro arquivo.

**Regra de confidencialidade:** aqui só entram conteúdos de cursos e exercícios de prática. Nunca publico materiais pagos na íntegra, nomes de colegas, dados de empresas reais nem informações internas de onde eu trabalho.

## Acessibilidade

Quero que qualquer pessoa consiga ler este material. Por isso:

- uso linguagem simples e explico cada termo técnico na primeira vez que ele aparece;
- organizo os textos com títulos, listas e tabelas com cabeçalho, para facilitar a leitura com leitores de tela;
- toda imagem tem descrição em texto (texto alternativo);
- nenhuma informação depende só de cor ou de ícone;
- os links dizem para onde levam.

Se algo estiver difícil de entender, abra uma *issue* (um pedido ou comentário aqui no GitHub).

## English

This repository is my learning journal on the path to becoming a **Product Owner (PO)**: the person who represents customers and the business inside the team, decides **what** gets built and **in which order**, and makes sure the product delivers real value.

I write down, in my own words, what I learn in each course, organized by the school or platform where I took it. The first one is **Tera**. The notes are my own summaries; the original materials belong to each school, and the links point to them.

### How this repository is organized

| Folder or file | What it contains |
| --- | --- |
| `cursos-courses/` | Courses, grouped by school, then by course, with one note per module |
| [`glossario-glossary.md`](glossario-glossary.md) | Product terms in Portuguese and English |
| `templates/` | Templates (user story, acceptance criteria, etc.) |
| `exemplos-examples/` | Exercises and artifacts I made while practicing |

**Confidentiality rule:** only course content and practice exercises go here. I never publish paid materials in full, classmates' names, real company data or internal information from where I work.

**Progress:** see the table in the Portuguese section above. Each course note is bilingual (PT/EN).

**Rule for new courses:** `cursos-courses/<school>/<course>/<number>-<module>.md`, lowercase with hyphens. Every note starts with a table naming the school, course, module, status and original source.

### Accessibility

Plain language, every technical term explained the first time it appears, clear headings, tables with headers, text descriptions for every image, no information conveyed by color or icons alone, and descriptive links. If something is hard to understand, please open an issue.
