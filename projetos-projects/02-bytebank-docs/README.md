## Checklist de boas práticas usado em todos os documentos / Writing checklist

Vem da Aula 03 (boas práticas de escrita e arquitetura da informação):

- [x] Um objetivo claro por documento (Aula 02).
- [x] Informação principal no início.
- [x] Ordem direta (voz ativa), frases curtas.
- [x] Falar com "você"; "nós/nosso" só para a própria empresa ("nosso atendimento").
- [x] Sem jargão solto: termos novos explicados ou ligados ao glossário.
- [x] Componentes certos para cada informação: sumário, listas numeradas para passos, tabelas para comparar, caixas de **IMPORTANTE**.
- [x] Hiperlinks com o destino no texto, nunca "clique aqui".
- [x] Sem adjetivos que julgam ("é muito fácil", "é difícil").
