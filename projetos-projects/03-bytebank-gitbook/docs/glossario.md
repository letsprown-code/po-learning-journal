# Glossário

> Documento de estudo. A Bytebank é fictícia.

*Termos financeiros que aparecem nesta documentação, explicados de forma simples.*

| Termo | O que significa |
|---|---|
| **DOC** | Transferência para outro banco que chega no próximo dia útil |
| **Extrato** | Lista de todas as entradas e saídas da sua conta |
| **Perfil de investidor** | Como você lida com riscos ao investir; ajuda a indicar os investimentos certos para você |
| **PIX** | Transferência instantânea, disponível a qualquer hora |
| **Resgate** | Tirar o dinheiro de um investimento e trazer de volta para a conta |
| **TED** | Transferência para outro banco que chega no mesmo dia útil |
