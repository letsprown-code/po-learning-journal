# Transferências

> Documento de estudo. A Bytebank é fictícia.

*Nesta página, você encontra como enviar dinheiro pela Bytebank e a diferença entre PIX, DOC e TED.*

## Contexto

Você pode enviar dinheiro para qualquer banco de três formas. A tabela mostra qual usar em cada caso.

| Tipo | Quando usar | Quando o dinheiro chega |
|---|---|---|
| **PIX** | Para enviar a qualquer hora, inclusive fins de semana | Na hora |
| **TED** | Para enviar a outro banco em dias úteis | No mesmo dia útil |
| **DOC** | Para enviar valores menores a outro banco | No próximo dia útil |

## Faça uma transferência

1. Na tela **Início**, selecione **Transferências**.
2. Escolha **PIX**, **TED** ou **DOC**.
3. Informe os dados de quem vai receber e o valor.
4. Confira o resumo e confirme com a sua senha do app.
